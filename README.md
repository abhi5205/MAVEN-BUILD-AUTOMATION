# 🚀 Build Automation using Maven

[![Java CI with Maven](https://github.com/abhi5205/MAVEN-BUILD-AUTOMATION/actions/workflows/maven.yml/badge.svg)](https://github.com/abhi5205/MAVEN-BUILD-AUTOMATION/actions/workflows/maven.yml)


## 📌 Objective
To automate the build process of a Java application using Maven.

## 🛠️ Tech Stack
- Java
- Maven

## ⚙️ Steps Performed
- Created Maven project using archetype
- Understood pom.xml structure
- Added JUnit dependency
- Built project using Maven lifecycle

## ▶️ Command Used
mvn clean install

## 📦 Output
- Generated JAR file inside `target/` directory

## ✅ Result
Build Successful 🎉

## 💡 Learning
- Maven lifecycle (clean, compile, test, package, install)
- Dependency management
- Build automation basics
